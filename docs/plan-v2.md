## 2. สามเสาหลัก

### A. ลื่น + เข้าใจง่าย
- แท็บหลักไม่เกิน 4 อัน ชื่อเดียวกันทั้งเว็บ ทุกจอมี **การกระทำหลักอย่างเดียว**
- เปิดครั้งแรกถามแค่ 1 คำถาม (เป้าหมายของคุณ) → จัดหน้า "วันนี้" ให้ทันที
- ภาษา: กริยาตรง ไม่หวาน ปุ่มบอกว่ากดแล้วเกิดอะไร (ตามแนว frontend-design)
- ตอบสนองทุกการแตะใน < 100ms (optimistic UI ที่มีอยู่แล้ว + สถานะกด)

### B. โหลดไว (วัดก่อน แล้วค่อยแก้)
ตอนนี้ (จาก `next build`): First Load JS หน้าแรก **227 kB**, Watch **290 kB**, Shorts **270 kB** · ยังไม่เคยวัด Lighthouse

| เป้าหมาย (มือถือกลางๆ 4G) | ค่า |
|---|---|
| LCP | < 2.0 วินาที |
| เวลาถึงภาพแรกของวิดีโอ | < 1 วินาที |
| INP | < 200 ms |
| CLS | < 0.05 |
| JS หน้าแรก | ≤ 170 kB |

วิธี:
1. แยกส่วน "ของทุกคน" ออกจาก "ของฉัน" → หน้า public เป็น static/ISR บน CDN ส่วนข้อมูลส่วนตัว (ดูต่อ, streak) โหลดตามมา → TTFB ลดมาก
2. โหลด Vidstack + hls.js เฉพาะตอนจะเล่น (dynamic import), เอา framer-motion ออกจากหน้าแรก
3. HLS เริ่มที่คุณภาพต่ำแล้วไต่ขึ้น, **โหลด manifest ของคลิปถัดไปล่วงหน้าตอน 30 วิสุดท้าย**
4. Suspense streaming แต่ละแถบบนหน้าแรก, รูป AVIF + `sizes` (มีแล้ว), ฟอนต์ไทย subset + variable
