# clip-ai: ลงคลิปใหม่ให้ครบ (ซับ + คำอธิบาย + chapters + แท็ก)

JR สั่งไว้ (7 พ.ย. 2026) ว่าทุกครั้งที่ลงคลิปใหม่ ให้ทำครบแบบนี้ทุกรอบ ไม่ต้องรอให้สั่งทีละอย่าง
สคริปต์อยู่ใน `scripts/clip-ai/` (ดู README.md ในโฟลเดอร์นั้น) รันจาก root ของ repo `topjgrind`

## ขั้นตอน
1) **หาคลิปที่ยังไม่ได้ทำ**: คลิปที่ JR บอก (id จาก URL `/watch/<id>` หรือ `/podcasts/<id>`) หรือใช้ `--missing` (= คลิปที่ยังไม่มีซับ)
   คลิปต้องอัปโหลดเสร็จแล้ว (media ready) และเป็น published หรือ scheduled ถ้ายังเป็น draft ให้ส่ง id ตรงๆ
2) **ถอดเสียง** (ใช้เครดิต ElevenLabs ราว 20 เครดิต/นาทีเสียง, key อยู่ใน `.env.local` = `ELEVENLABS_API_KEY`):
   `node --env-file=.env.local scripts/clip-ai/transcribe.mjs <id…|--missing>`
   ได้ `.clip-ai/<id>/scribe.json` + `transcript.txt` (รันซ้ำไม่เสียเงิน ยกเว้นใส่ `--force`)
3) **ทำซับ**: `node scripts/clip-ai/vtt.mjs <id…>` ได้ `.clip-ai/<id>/captions.vtt`
4) **เขียนคำอธิบาย + chapters + แท็ก**: อ่าน `transcript.txt` ทั้งไฟล์ แล้วเขียน `.clip-ai/<id>/meta.json` ตาม `scripts/clip-ai/DESCRIPTION-GUIDE.md` (เสียง JR, เขียนจากบทจริงเท่านั้น, แท็กจากชุด 17 แท็กเท่านั้น)
   ถ้าคลิปเยอะและบทยาว แบ่งให้ subagent ช่วยเขียนได้ (กลุ่มละไม่เกิน ~200 KB ของ transcript) แล้วตรวจรวมเองก่อนใส่
5) **ตรวจก่อนใส่**: `node --env-file=.env.local scripts/clip-ai/apply.mjs <id…> --dry-run`
   ตรวจด้วยตาว่า: บรรทัดแรกแทงจริง ไม่มีคำต้องห้าม/ขีดยาว ไม่มีตัวเลขที่คลิปไม่ได้พูด chapters เวลาตรงกับบท
6) **ใส่ลงเว็บ**: `node --env-file=.env.local scripts/clip-ai/apply.mjs <id…>`
   สคริปต์สำรองค่าเดิมไว้ใน `backups/clip-ai-<เวลา>.json` ก่อนเขียนเสมอ (เขียนแบบเดียวกับปุ่มบันทึกใน Studio)
   เว็บดึงข้อมูลใหม่เองภายใน ~30 วินาที (catalog cache)
7) **เช็กบนเว็บจริง**: เปิด `https://topjgrind.com/watch/<id>` ดูว่าคำอธิบายขึ้น, มีปุ่ม CC, และ chapters แบ่งในแถบเวลา
8) **บอก JR**: สรุปสั้นๆ ว่าทำคลิปไหน, เครดิตที่ใช้, แท็กที่เลือก และจุดที่ไม่แน่ใจ (คำที่ฟังไม่ชัด, คลิปที่ชื่อไม่ตรงเนื้อหา)

## ข้อควรระวัง
- ห้ามพิมพ์ค่า API key ออกมาในแชตหรือ log
- ไฟล์ใน `.clip-ai/` ไม่ขึ้น git (มีเนื้อหาคลิปสมาชิก) ถ้า JR อยากอัป .vtt เองใน Studio → คำบรรยาย ให้ชี้ไฟล์ `.clip-ai/<id>/captions.vtt`
- ถ้า Bunny ตอบ 403 ตอนดึงเสียง: ต้องส่ง header `Referer: https://topjgrind.com/` (ใน lib.mjs ทำไว้แล้ว)
- ถ้า ElevenLabs ตอบ 401/402: key หมดอายุหรือเครดิตหมด ให้บอก JR อย่าเปลี่ยนไปใช้ทางอื่นเองโดยไม่ถาม
- ห้ามทับคำอธิบายที่ JR เขียนเองโดยไม่บอก ถ้าคลิปมีคำอธิบายอยู่แล้ว ให้เก็บประเด็นของเขาไว้ แล้วแจ้งในสรุป
